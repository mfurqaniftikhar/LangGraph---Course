# LangGraph: Building Advanced AI Agents & Multi-Agent Systems

Welcome to the **LangGraph Course** repository! This hands-on course is designed to take you from the basics of LLM orchestration to building complex, stateful, and cyclic multi-agent AI applications using LangGraph and LangChain.

Whether you want to build an autonomous research assistant, a customer support bot, or collaborative AI teams, this repository has everything you need.

---

## 🚀 Course Highlights
*   **Core Concepts:** Understanding Nodes, Edges, State, and Graphs.
*   **State Management:** How to maintain memory and context in complex AI loops.
*   **Human-in-the-Loop:** Adding manual approval and interruption steps in agent workflows.
*   **Multi-Agent Architectures:** Building teams of agents that collaborate to solve tasks.
*   **Streaming & Production:** Deploying and monitoring agents efficiently.

---

## 🛠️ Tech Stack Used
*   **Framework:** LangGraph, LangChain
*   **Language:** Python
*   **LLM Providers:** OpenAI (GPT), Anthropic (Claude), or Open-source models (Ollama)

---

## 📂 Repository Structure
*   `01_Introduction_to_Graphs/` - Basic LangGraph setup, nodes, and edges.
*   `02_State_and_Memory/` - Managing application state and memory.
*   `03_Human_in_the_loop/` - Intercepting agent actions for human feedback.
*   `04_Multi_Agent_Teams/` - Creating collaborating agents (e.g., Researcher + Writer).
*   `projects/` - Full-scale end-to-end agentic applications.
